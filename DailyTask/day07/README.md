# Day 7: Collections Framework Part 1

## Objective
To understand and implement Java Collections using
a Library Waitlist application.

## Collections Used
- ArrayList: Library catalogue
- LinkedHashSet: Duplicate-free waitlist requests
- HashSet: Unique student IDs
- ArrayDeque: Regular FIFO waitlist
- PriorityQueue: Faculty-first requests

## Iteration
- For-each loop
- Iterator.remove()
- ListIterator

## Exception Demonstration
Demonstrated unsafe collection modification and
the safe iterator-based removal approach.

## Performance Testing
Compared ArrayList and LinkedList insertion and
indexed get(i) access.

## Execution
javac LibraryWaitlist.java CollectionPerformance.java
java LibraryWaitlist
java CollectionPerformance
